# Orabit Security Notes

## ما يحميه التصميم

- مزود الاستضافة لا يرى نص الرسائل أو الملفات.
- AES-GCM يوفر السرية وسلامة النص المشفر.
- HMAC يضيف تحققًا صريحًا من سلامة الحزمة.
- ECDH يمنع إرسال مفتاح الجلسة بصورته الصريحة.
- التخزين الافتراضي للمحتوى محلي في IndexedDB.

## المخاطر والتخفيف

| الخطر | التخفيف |
|---|---|
| صفحة GitHub Pages معدلة أو XSS | CSP، مراجعة تغييرات المستودع، تجنب سكربتات CDN غير المثبتة |
| هجوم الوسيط أثناء الإشارة | مقارنة رمز الأمان عبر قناة مستقلة |
| تسرب مفتاح من جهاز مخترق | لا يمكن لواجهة الويب حماية جهاز مصاب؛ استخدم جهازًا موثوقًا |
| فقدان السجل | النسخ الاحتياطي اليدوي المشفر؛ لا يوجد سحابة تلقائية |
| NAT يمنع الاتصال | STUN اختياري أو TURN موثوق؛ TURN يرى metadata الشبكة |
| حجم Data Channel | chunking، backpressure، وحدود حجم قابلة للضبط |
| إعادة إرسال حزم قديمة | أضف counter/nonce state وReplay protection في الإصدار الإنتاجي |
| Forward Secrecy غير مكتملة | نفذ Double Ratchet أو تجديد ECDH دوريًا قبل اعتماد أمني |
| صلاحيات الميكروفون | اطلبها عند الضغط فقط وأوقف المسارات بعد التسجيل |

## ملاحظات تنفيذية

لا تُدخل كلمات مرور أو مفاتيح ثابتة في المستودع. لا تعتبر رمز الأمان إثباتًا تشفيريًا مستقلًا؛ هو بصمة مفيدة للمقارنة ويجب تحسين اشتقاقه وتوثيق المصافحة في إصدار إنتاجي. أي ادعاء "أمان كامل" غير مناسب دون تدقيق خارجي.
