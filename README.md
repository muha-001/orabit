# Orabit

**Orabit** منصة دردشة ويب مباشرة ومشفرة من طرف إلى طرف، تعمل كملفات ثابتة على GitHub Pages. لا توجد قاعدة بيانات أو خادم رسائل تابع للمشروع؛ بعد الإشارة، تنتقل البيانات عبر WebRTC Data Channel بين المتصفحات.

> **تنبيه أمني:** هذا مشروع مفتوح المصدر ونسخة MVP تعليمية. لا تستخدمه لحماية معلومات حساسة قبل مراجعة مستقلة واختبارات اختراق وتدقيق للكود.

## المزايا

- تشفير AES-256-GCM للمحتوى مع HMAC-SHA-256 للتحقق من العبث.
- تبادل مفاتيح ECDH P-256 واشتقاق HKDF.
- اتصال WebRTC مباشر مع STUN اختياري لعبور NAT.
- تبادل SDP يدويًا بالنسخ واللصق.
- رسائل عربية وإنجليزية، RTL/LTR، وضع ليلي ونهاري.
- تسجيل صوت وإرساله مشفرًا، ونقل ملفات مجزأة إلى أجزاء 16KB.
- IndexedDB محلي فقط، مع زر مسح السجل.
- Service Worker للعمل دون اتصال بعد أول زيارة.

## التشغيل

يمكن فتح `index.html` عبر خادم HTTPS محلي، لأن الميكروفون وWebRTC يحتاجان secure context. مثال:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## اتصال مستخدمين

1. افتح Orabit في جهازين.
2. على الجهاز الأول اضغط **إنشاء عرض**، ثم انسخ رمز الإشارة.
3. انقل الرمز يدويًا إلى الجهاز الثاني عبر قناة خارجية، ثم اضغط **إنشاء إجابة**.
4. أعد رمز الإجابة إلى الجهاز الأول واضغط **تطبيق الرمز**.
5. بعد ظهور الاتصال، قارن رمز الأمان المعروض قبل تبادل معلومات خاصة.

## النشر على GitHub Pages

1. أنشئ مستودعًا باسم `orabit`.
2. ارفع الملفات إلى فرع `main`.
3. من **Settings → Pages** اختر **Deploy from a branch** ثم `main` و`/root`.
4. احفظ وانتظر بناء الصفحة.
5. استخدم رابط HTTPS الناتج؛ GitHub Pages يوفر HTTPS تلقائيًا.

## البنية

| الملف | المسؤولية |
|---|---|
| `index.html` | الواجهة والهيكل الدلالي |
| `style.css` | التصميم المتجاوب |
| `crypto.js` | ECDH/HKDF/AES-GCM/HMAC |
| `webrtc.js` | PeerConnection وData Channel وSDP |
| `file-transfer.js` | تقسيم الملفات وإعادة التجميع |
| `audio.js` | MediaRecorder |
| `storage.js` | IndexedDB المحلي |
| `app.js` | منطق التطبيق والترجمة |
| `sw.js` | التخزين المؤقت دون اتصال |

## القيود المعروفة

لا يوفر GitHub Pages signaling ديناميكيًا. النسخة الحالية تعتمد على النسخ واللصق، وQR يحتاج مكتبة توليد QR موثوقة إن أضيف لاحقًا. STUN لا يضمن الاتصال في كل الشبكات؛ قد يلزم TURN خارجي، وهذا يضيف وسيطًا شبكيًا ولا ينبغي أن يرى المحتوى المشفر. حذف بيانات المتصفح يؤدي إلى فقدان السجل المحلي.
